# Claude Project Instructions

## Script Organization

- **Always write random one-off scripts in the `./tmp` directory**. This
  keeps temporary scripts separate from the main codebase and makes them
  easy to identify and clean up later.

## Code Style

- Follow existing code patterns and conventions in the codebase
- Use TypeScript where applicable
- Maintain consistent formatting

## File Organization

- Keep documentation in appropriate directories
- Use clear, descriptive filenames
- Group related files together logically
